# File Metadata Privacy Checklist

A practical checklist for reviewing hidden metadata before sharing photos, screenshots, PDFs, Office documents, videos, and audio files.

## Why this matters

Files can contain hidden metadata that may reveal your identity, location, device, software, company, workflow, or editing history.

Metadata removal is not the same as redaction. You should review visible content first, then clean hidden metadata before sharing the final copy.

## Quick checklist

| File type | Metadata to review | Visible content to review |
|---|---|---|
| Photos | GPS location, camera model, timestamp, editing software | Faces, license plates, home/workplace landmarks |
| Screenshots | Software fields, timestamps, file paths | Browser tabs, URLs, notifications, account names |
| PDFs | Author, title, subject, creator, producer, creation date, modified date | Comments, annotations, form fields, attachments |
| Office documents | Author, last modified by, company, manager, template, custom properties | Tracked changes, comments, hidden sheets, speaker notes |
| Videos | Creation time, device model, encoder, location fields | Faces, voices, screens, backgrounds |
| Audio | Title, artist, album, comments, copyright, encoder, cover art | Spoken names, background conversations, private locations |

## Safe sharing workflow

1. Review visible content first.
2. Export or duplicate the final file.
3. Inspect hidden metadata.
4. Remove sensitive metadata locally when possible.
5. Share the cleaned copy.
6. Keep the original private if you still need archival metadata.
